# UI 开发上下文

> 状态更新（2026-08-18）：本文保留从“考试”项目迁入的设计上下文。后续确认已将首发范围收敛为 **Night-only、macOS、DSH Web + DSH Desktop**；包名为 `dsh-yamada-night-shift`。当前可执行插件位于 `yamada-night-shift/`，最终资产位于 `assets/final/`，真实预览位于 `yamada-night-shift/preview/`。

## 1. 项目目标

制作一个可被 DeepSeek Harness 正式识别、安装、切换和卸载的桌面 UI 皮肤/插件，并发布到 GitHub。项目不仅追求“换图”，还要具备完整主题体验、稳定兼容性、低安装门槛和足够强的 README 首屏传播力，以争取 GitHub Stars。

## 2. 原始产品方向（历史记录）

当前选定方向是《在超市后门吸烟的二人》的山田/田山昼夜人格主题：

- 白天：栗红短发、米色衬衫、酒红围裙，明亮、亲和、适合日常工作。
- 夜晚：酒红发色、黑色皮夹克、颈圈、浅色裙装、黑丝袜、白靴，成熟、飒爽、适合深色专注模式。
- 桌面端优先，不做营销落地页式界面。
- 保留 DeepSeek Harness 真正需要的对话、代码 Diff、工具执行、文件变更、Git、终端与输入区。

## 3. 设计决策与最终收敛

### 布局

- 窗口使用全宽开发工作区。
- 左侧保留窄导航栏。
- 中央代码/对话区是视觉和功能主区，必须获得最大宽度。
- 右侧工具运行、Agent Notes、Files Changed、Git 等面板使用剩余空间。
- 禁止设置独立人物右栏；它会挤占代码宽度。
- 人物放入应用画布内部的背景层，位于中右侧或右侧空白区域。

### 层级与可读性

- 功能层级：代码编辑器 > 工具面板 > 角色装饰。
- 代码与正文背后使用约 90–95% 不透明深色面板。
- 与人物重叠的工具卡片使用约 88–94% 的烟熏玻璃面板。
- 人物不能覆盖代码、按钮、输入框或重要状态。
- 背景环境可以暗，但角色不能变成低透明度幽灵；人物第一眼必须可辨认。

### 人物明暗

- 人物视觉强度目标约为 80–90%，而不是早期尝试的 25–35%。
- 面部、红瞳、酒红发色、浅色裙装、抬手和白靴需要局部主光。
- 头发和皮衣可加轻微冷蓝绿色轮廓光。
- 人物背后局部压暗，形成剪影分离；不要整体提亮背景。
- 酒红发色与肤色可适度增加饱和度，但不能霓虹化。

### 角色姿态和造型基线

- 采用倚靠金属服务门的放松姿态。
- 头部略歪，带冷静、略戏谑的半笑。
- 一只手在脸侧夹烟，另一只手插入皮衣口袋。
- 腿部放松交叉。
- 夜间造型：酒红齐刘海短发/侧边长发束、红瞳、黑色扣带颈圈、深色短皮衣、浅色系带短裙、半透明黑丝袜、白色短靴。
- 左侧头像与主人物保持同一身份和造型。

### 主题系统

- 历史方案曾考虑 Day / Night 两种人格主题；首发已确认只保留 Night，浅色系统主题下仍显示夜间视觉。
- 共享强调色可使用酒红；白天使用暖米白、炭黑与柔和阴影，夜间使用煤黑、沥青灰、冷蓝绿和少量暖琥珀光。
- 可加入“人物背景透明度/强度”设置，但默认值应确保人物清晰。
- 烟雾只可作为细微的任务进度或状态动效，不能遮挡内容。

## 4. DeepSeek Harness 接入实现

最终实现基线：

- 根据用户确认，直接以本机已安装的 `dsh-deep-whale/maid-atelier` 生命周期和插件结构作为兼容性脚手架，并保留 CC BY-NC-SA 4.0 与 NOTICE 署名。
- 未保留参考皮肤的女仆图片、宫殿图片和装饰 WebP；运行时只包含本项目生成的人物与夜间背景。
- 具备安装、互斥切换、卸载还原、响应式窗口和行为测试；亮/暗 DSH 状态均统一映射到 Night 视觉。
- 目标发布形态应包含清晰的皮肤描述文件、客户端主题代码、素材构建、测试、LICENSE、NOTICE、安装说明和截图。

当前包遵循 `skin.json`、`cordis.patch.yml`、`dsh.client`、预构建 `lib/` 的已安装 DSH 插件结构；发布前仍应在目标 DSH 版本做一次快速回归。

## 6. 版权与发布风险

山田/田山是可识别的现有 IP 角色。免费、非商业、注明学习用途或 AI 重新绘制，都不自动等于获得授权。开发阶段可以继续按现有视觉基线实现，但公开发布前必须做明确选择：

1. 获得角色与素材使用许可；或
2. 仅发布皮肤引擎与用户本地导入功能，不分发受保护角色素材；或
3. 将默认角色替换为具有相同昼夜气质、但不指向具体 IP 的原创人物。

`dsh-deep-whale/maid-atelier` 此前被识别为 CC BY-NC-SA 4.0 衍生链，不应在没有满足署名、非商业和相同方式共享要求的情况下复制其具体实现或素材。

## 7. 继续开发时的验收基线

- 插件/皮肤格式、构建与包内容校验通过。
- 能安装、启用、在其他皮肤间互斥切换、禁用和干净卸载。
- 不破坏原 DSH 功能和交互。
- 常见桌面宽度下代码区不因人物明显缩窄。
- 代码、工具卡、输入框与按钮达到稳定可读对比度。
- 人物清晰但不抢占操作层。
- 无外部追踪、无隐式网络素材请求、无密钥。
- 测试覆盖切换、重复安装、卸载还原、缺失素材和窗口尺寸变化。
