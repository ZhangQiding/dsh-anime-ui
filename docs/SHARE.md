## 中文短文案

给 DeepSeek Harness 换了一个「山田的夜班」主题：

- DSH Web + macOS DSH Desktop
- 夜间动漫风 UI，原生会话和工具交互不变
- 本地相册，PNG/JPG/JPEG 一键设为背景
- Desktop 重启后仍能恢复背景

仓库与安装说明：<https://github.com/ZhangQiding/dsh-anime-ui>

如果你也在用 DeepSeek Harness，欢迎试试并点个 Star；遇到问题直接开 Issue。

## English short copy

Yamada Night Shift is a night-only anime presentation skin for DeepSeek Harness Web and macOS Desktop. It keeps the native DSH workflow intact and adds an optional local photo album with persistent PNG/JPG backgrounds.

Install: <https://github.com/ZhangQiding/dsh-anime-ui>
